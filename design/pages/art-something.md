## Motion

Not defined for this project.

The page has motion but no shared tokens yet: the prompt rise, the score press and floating points, and the crumble, in the `.art-*` rules and `TimeAndScore.tsx`, `PromptDisplay.tsx` and `crumble.ts`.

## Components

### Time and score box

- A hard offset shadow in `padauk`: 10px, or 6px on phones. Set in plain CSS (`.art-score-box`) so the press can animate it.
