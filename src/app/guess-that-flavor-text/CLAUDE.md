# Guess That Flavor Text

A daily puzzle: everyone gets the same Pokémon TCG card's flavor text and names the
Pokémon. Lifelines (set, stage, attack) each cost a point. A wrong guess gets one
redemption try, worth half a point, with two more hints.

- **Design:** palette, font and page rules are in `design/pages/guess-that-flavor-text.md`.
- **Page CSS:** `layout.tsx` (dot-grid background, own scroll container) and the result-page reveal animations (`.card-reveal-*`, `.result-*`, `.reveal-pending`) and `.gtft-scrollbar` in `globals.css`.

## Files

- `GuessThatFlavorText.tsx`: game state, daily card pick, saving, name matching, lifelines.
- `GTFTIntroPage.tsx`, `GTFTGamePage.tsx`, `GTFTResultPage.tsx`: the three screens.
- `chatter.ts`: Unknown Q's talking squash (`startChatter`), played on the game page's logo while the flavor text types in, and the spit that gives out the redemption hints (`spitHints`).
- `CardReveal.tsx`: the result card, its reveal and finale animations and star burst, and which reveal and finale play each day.
- `flavor-cards.ts`: card data, generated by `npm run fetch-flavor-cards` (`scripts/fetch-flavor-cards.mts`, from the pokemontcg.io API). Don't edit by hand. Each card's `generation` comes from its first National Pokédex number.
- `pokemon-names.ts`: names for the guess autocomplete, plus `getPokemonSpriteUrl` (Limitless sprites, including regional forms and paradox Pokémon).
- `dates.ts`: local calendar-day helpers.

## Things to know

- The daily card comes from the local date, and the puzzle number counts from the start date in `GuessThatFlavorText.tsx`. Changing the card list or the pick formula changes today's card for everyone.
- A game is saved in `localStorage` per day; the key format predates `dates.ts` and is kept so saved games still load. The streak is saved separately on the result page.
- The page reloads into the new puzzle when the date changes.
- Guesses must be picked from the autocomplete. Matching is in `namesMatch`: a card named exactly after a Pokémon needs that Pokémon; other card names accept the Pokémon's name as whole words.
- After a guess, the unused lifelines reveal one by one before the result page; these reveals don't cost points.
- Redemption: after a wrong first guess (and those reveals), Unknown Q spits out the card's type and generation, shown as its games, e.g. "Ruby & Sapphire" (`redemptionHints`) and the player gets one more guess. The wrong guess stays in the guess box, read-only, until the lifelines, the shake and the spit are done (`guessLocked`, timed with `spitDurationMs`); it fades out as its pill (crossed out, with a gray sprite) appears, and then the box clears. Right is half a point (`score: 0.5`, `redeemed: true`), wrong is 0. A card with neither hint skips redemption. The wrong guess is saved as `firstGuess`, so a game reloaded mid-redemption comes back to it with the hints already out. Games saved before redemption lack these fields.
- A redeemed result's heading reads REDEMPTION instead of CORRECT.
- Half a point shows as ½ (`formatScore` on the result page, and in the share text) and as a half star (`Star`'s `half`).
- The result page has a dev-only reset button (localhost or `?dev`). In dev, a picker under the result replays it with any reveal (`spotlight`, `smoke`, `ink`, `zigzag`), finale (`big-pop`, `shake`, `jelly`, `tada`) and star burst on or off. It sets `?reveal=`, `?finale=` and `?stars=1|0`, which force them on load.
- The reveal and finale change daily, picked from the puzzle number by `dailyPick`: each plays once per run of days (one day each), in a shuffled order, never the same two days running. The two lists are shuffled with different salts so they don't pair up the same way. Adding or removing one reshuffles that list.
- The star burst plays only on a right guess. The section clips horizontal overflow so the stars can't make the page scroll sideways.
- The card image must hide itself until its reveal's cover is drawn (`.card-reveal-img`). A cover alone isn't enough: mobile browsers can paint the image a frame first. Reveals with a sprite mask (`public/gtft-reveal-*.png`) wait for it to load, since an unloaded mask hides the cover.
