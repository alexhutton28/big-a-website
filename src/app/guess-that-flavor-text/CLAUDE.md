# Guess That Flavor Text

A daily puzzle: everyone gets the same Pokémon TCG card's flavor text and names the
Pokémon. Lifelines (set, stage, attack) each cost a point.

- **Palette:** `tide`, `wave`, `splash`, `stone`, `slate`, `ghost`, `drop`, `mist`, `abyss` (tokens in `src/app/globals.css`). Font: Barlow (the `barlow` class).
- **Page CSS:** `layout.tsx` (dot-grid background, own scroll container) and the result-page reveal animations (`.result-*`, `.reveal-pending`) and `.gtft-scrollbar` in `globals.css`.

## Files

- `GuessThatFlavorText.tsx`: game state, daily card pick, saving, name matching, lifelines.
- `GTFTIntroPage.tsx`, `GTFTGamePage.tsx`, `GTFTResultPage.tsx`: the three screens.
- `flavor-cards.ts`: card data, generated by `npm run fetch-flavor-cards` (`scripts/fetch-flavor-cards.mts`, from the pokemontcg.io API). Don't edit by hand.
- `pokemon-names.ts`: names for the guess autocomplete, plus `getPokemonSpriteUrl` (Limitless sprites, including regional forms and paradox Pokémon).
- `dates.ts`: local calendar-day helpers.

## Things to know

- The daily card comes from the local date, and the puzzle number counts from the start date in `GuessThatFlavorText.tsx`. Changing the card list or the pick formula changes today's card for everyone.
- A game is saved in `localStorage` per day; the key format predates `dates.ts` and is kept so saved games still load. The streak is saved separately on the result page.
- The page reloads into the new puzzle when the date changes.
- Guesses must be picked from the autocomplete. Matching is in `namesMatch`: a card named exactly after a Pokémon needs that Pokémon; other card names accept the Pokémon's name as whole words.
- After a guess, the unused lifelines reveal one by one before the result page; these reveals don't cost points.
- The result page has a dev-only reset button (localhost or `?dev`).
