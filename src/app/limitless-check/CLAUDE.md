# Limitless Check

Higher-or-lower on Pokémon TCG tournament play: pick which card, deck or player has
more entries in recent Play Limitless tournaments. A correct pick keeps the winner on
the left for the next round; a wrong pick ends the run.

- **Palette:** the Pokémon-named tokens (`houndoom`, `eevee`, `rockruff`, `scizor`, `butterfree`, `blissey`, `togepi`, `jigglypuff`, `bulbasaur`) in `src/app/globals.css`. Paper background: `public/paper-bg.jpg`.
- **Page CSS:** the `limitless-check-scrollbar` and game-over overlay rules in `globals.css`.

## Files

- `limitlessCheck.tsx`: menu, rounds, score and restart.
- `MenuScreen.tsx`, `GameScreen.tsx`, `GameOverScreen.tsx`: the screens.
- `gameLogic.ts`: building rounds and checking guesses (pure functions).
- `starterItems.ts`: the item pool for each mode (all, cards, decks, players).
- `types.ts`: `GameItem` and friends.

## Data

- `cards-generated.ts` (+ `cards-data.json` checkpoint) is generated by `npm run fetch-cards`; `decks.ts` by `npm run fetch-decks`. Both rebuild a rolling recent-window snapshot from the Play Limitless API; the window, filters and deck taxonomy are at the top of `scripts/fetch-cards.mjs` and `scripts/fetch-decks.mjs`. Don't edit the generated files by hand.
- Play Limitless only covers online tournaments on that platform, not major in-person events.
- `players.ts` is a hand-picked list.
- The "last updated" date shown in the game comes from the generated files.
- Refreshing the data: run the fetch scripts, then open a PR with the regenerated files (past refreshes were titled "Refresh Limitless Check data (last 30 days)").
- `cards-test.ts` isn't imported anywhere.
